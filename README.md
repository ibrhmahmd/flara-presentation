# Flara partnerships project

Ibrahim Ahmed's (Rights Hero) work on growing **Flara** (flara.io, Rights Hero's AI film studio) through Egyptian STEM academies and student competitions, using LEGO Education's business model as the template.

Start with `HANDOFF.md` for the current state and next steps.

## Decks

Each deck is one self-contained folder. Open `index.html` in a browser (double-click, or VS Code Live Server).

| Deck | Audience | Folder | Status |
|---|---|---|---|
| Flara Growth Plan (8 slides) | Rights Hero leadership | `management/` | Fresh skeleton, to rework slide by slide |
| Flara for Partners (13 slides) | Academy owners and competition directors | `partners/` | Ready, placeholders to fill |

Keys: ←/→ or space to move, Home/End, **N** speaker notes, **F** fullscreen. The URL hash (`#5`) is the slide number.

Each folder holds `index.html` (all slides as `<section>`s, notes in `<aside>`), `context.md` (audience, asks, placeholders), and an identical copy of the design system `deck.css` + runner `deck.js`. If you change one copy, copy it to the other folder.

The tech-principal proposal is a claude.ai doc: [Flara: Proposed Business Model and Partnerships](https://claude.ai/artifact/FzvyfkwuFPHm5Zg6tQndeV). Local copy: `docs/tech-principal-proposal.md`.
