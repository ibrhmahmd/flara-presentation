# Ibn Battuta · Text-to-Speech

Studio: **Text to Speech**. Fields: Title, Language, Voice (with a Male/Female filter and samples), Audio Text (up to 3,000 characters). There is no style or speed field, so **the voice you pick is the style**: use the same voice for every line so it sounds like one narrator.

**Voice choice (do once):** Language **Arabic** → Filter by Gender **Male** → preview the samples → pick the calmest, warmest voice with clear classical (fusha) pronunciation. Write its name here: `________`. Use the same voice in the Narration voice field of Films 1 and 2.

The lines are Ibn Battuta's own words from the Rihla (the game's research, with page numbers). Paste them exactly; the tashkeel (vowel marks) helps pronunciation. If **Saleh** (named in the game docs as the reader) is a student, record his real voice instead: student-made work is stronger, and TTS is the backup.
