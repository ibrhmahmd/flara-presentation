# Crab Quest · Arabic subtitles

The films and the ad are narrated in **English** (the game's language). Arabic is for parents and the audience vote. Studio: **Video Translation**, which has no prompt: you set only these fields. It returns a dubbed video and an **SRT subtitle file**.

| Field | Value |
|---|---|
| **Video File** | `crab-quest-intro.mp4`, then `crab-quest-ad.mp4` (each separately) |
| **Target Language** | Arabic |
| **Translation Title** | e.g. Crab Quest Intro AR |

**Main use:** keep the English video and add the **Arabic SRT** as subtitles (in CapCut or a similar editor, or upload it next to the video on YouTube). Use the Arabic dubbed video only for parents' WhatsApp groups if it sounds natural.

**Check the subtitles:** the crab should be «السلطعون الصغير», and the game title stays "Crab Quest" in Latin letters. Fix anything that sounds machine-translated before publishing.
