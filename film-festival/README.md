# Film Festival: "The Dark Room"

A Flara use case for the AAFFIAT Film Festival (February 2027 round), built from the forum's rules. It is both a demo for the academies and the sample project instructors will teach from.

Rules PDF: `../context/aaffiat-rules/film-festival-rules.pdf`. Summary of all forum competitions: `../context/aaffiat-competitions.md`.
